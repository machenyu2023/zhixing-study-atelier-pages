# 遥感物理个人学习资料库

本库用于长期建立、维护和使用遥感物理知识体系。初始化日期：2026-09-12。

## 学习主线

地表状态 → 电磁波与目标相互作用 → 反射 / 吸收 / 散射 / 发射 → 大气传播 → 传感器观测 → TOA 信号 → 前向模型 → 参数反演。

这是一条解释问题的主线。实际建模时，传感器响应是从到达传感器的信号生成观测数据的环节；主动遥感还需明确发射端及往返传播路径。各分支的物理过程以具体模型为准。

## 日常协作

提出概念问题时，先定位知识地图，再解释物理过程；值得长期保留的内容写入相应条目。提供论文、教材、ATBD、网页、PDF、笔记或代码时，先检索现有条目，再决定补充、合并或建立新条目。

同一概念只维护一个主条目，其他板块用链接引用。不同模型保留独立条目，并用模型对比表连接。来源未核验的结论明确标注，不能成为已验证知识的依据。
