## 审计维度与入库门槛

1. **科学正确性**：定义、量纲、极限情形、几何和极化约定一致；不把教学近似写成产品算法。
2. **证据完整性**：每个关键公式至少有教材或官方文档支撑；来源登记保存 DOI/URL、版本、访问日期和页码/章节。只看到摘要或目录时，状态写“已定位待精读”。
3. **解释质量**：按“地表状态 → 相互作用 → 传播 → 传感器 → TOA 信号 → 前向模型 → 反演”串起文字；每个变量写物理意义和单位。
4. **模型可比性**：不同模型单独建条目，另外维护模型对比表；明确输入、输出、假设、参数范围、误差来源和适用场景。
5. **可复现实验**：实验说明问题、预测、方程、单位、控制变量、输出和边界；运行结果写入变更记录，未运行的内容标记为设计稿。
6. **产品可追溯性**：真实卫星产品必须注明观测量、定标、波段响应、质量标识和产品版本，避免用中心波长或示意公式代替通道积分。
