## 首批八主题实施队列

| 队列 | 主题 | 依赖与交付 |
|---:|---|---|
| 1 | 立体角与观测几何 | 画清太阳—地表—传感器方向，验证投影面积和 \(d\Omega\) |
| 2 | 辐射亮度、辐照度与通量 | 统一 \(L/E/\Phi\) 定义、单位和有限视场/半球积分 |
| 3 | 光谱量、波长/频率与单位换算 | 解释 \(B_\lambda/B_\nu\)，完成量纲与数值换算实验 |
| 4 | 反射率、BRDF 与反照率 | 建立方向性反射关系，注明 sr⁻¹ 与无量纲量的差异 |
| 5 | 吸收、散射、消光与光学厚度 | 把介质过程拆开，验证 Beer–Lambert 极限 |
| 6 | 透过率与辐射传输方程 | 区分地表项、路径项和多次散射，写出最小前向模型 |
| 7 | 传感器响应、波段积分与定标 | 将连续谱连接到 DN、通道亮度和质量标识 |
| 8 | TOA 反射率、Surface Reflectance 与大气校正 | 用前七项解释 Landsat 产品链和干扰因素 |

每个队列条目完成后，必须在来源登记中留下精确定位，在条目中保留变量单位和假设，并在变更记录中记录实验或检查结果。

## 跨主题联系

- 光学路径：辐射量与几何 → 地表方向性反射 → 大气传播 → TOA 信号 → 地表反射率反演。
- 热红外路径：温度与发射率 → 地表热辐射及环境辐射反射 → 大气传播 → 通道观测 → LST 反演。
- 被动微波路径：土壤/植被状态 → 介电与辐射特性 → 传播与接收 → 微波亮温 → 土壤水分反演。
- 主动微波路径：雷达发射 → 传播 → 目标散射 → 返回传播 → 接收回波 → 定标后散射量及参数反演。
