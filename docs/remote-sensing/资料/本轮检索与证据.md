# 本轮检索与证据

核验日期：2026-09-13。本轮登记 12 个新来源，另重读了 USGS Surface Reflectance 页面。专题正文约 1.4 万字符，覆盖十二个板块的一篇代表条目；其余条目尚未全部重写。来源记录不能替代学术全文精读。

检索采用 Crossref `query.bibliographic`，每个查询返回 3 个候选，以作者、题名、年份和 DOI 筛选并去重。查询分别为 Rodgers 反演教材、Jacquemoud PROSPECT+SAIL 综述、Vermote 6S 概述及 Dobson 湿土介电混合模型。先检索元数据，再用 USGS、NASA GSFC、ESA、JPL 与模型开发者页面核对产品和软件定义。

这轮没有可用的学术 MCP 检索连接器，使用公共 HTTP 接口。Crossref 两项请求最初返回 429，单独重试后成功；UMass 旧 MODIS 地址和 ARTMO 两个旧模型地址返回 404，NASA Earthdata 的 SAR 地址返回 403。随后读取 NASA GSFC MODIS、ESA Instrument 和 PROSAIL 作者仓库作为替代。不能把失败页面列为已阅读来源。

## 核验中保留的问题

USGS SR 页面缩放段落有把 SR 写成 Surface Temperature 的表述错误，表格也夹有旧产品格式；这里只采用 SR 公式和明确的算法区别，不照搬错误表头。ST 页面新旧辅助数据段落存在不同步，因此文章不固定所有年份的辅助数据源。MODIS GSFC 页面含 V006 信息，本轮只引用产品类型与观测窗口。PROSAIL README 参数表的水厚度、干物质上限可疑且有旧环境说明，本轮未采纳其数值范围。

## 数学与实验的来源边界

辐射收支、标量 RTE、简化地表—大气多次反射、单色热辐射、Fresnel、Stokes、tau–omega、Beer 间隙概率和线性高斯更新均为教学推导，非逐字转录 ATBD。数值均为合成例子，未验证真实卫星反演精度。本轮没有运行 6S、PROSAIL 或任何 SMAP 产品生成流程。

## 下轮精读优先项

优先取得 SMAP L2 被动 ATBD 的可定位正文，核对 tau–omega 参数和介电模型；读取 MCD43 当前集合用户指南及核定义；精读 PROSPECT+SAIL 综述的模型假设和验证。由论文参考文献向前追溯原模型、向后寻找改进工作，保留不同版本和未解决分歧。

## 可复现检索

运行 `python scripts/collect-remote-sensing-sources.py --output-dir tmp/source-review`。检索器需要 Python 3 和 beautifulsoup4，仅获取来源；每次记录 URL、UTC 时间、HTTP 状态与 SHA-256。失败记录不会被标成科学核验成功。原网页文本保存在被 Git 忽略的 tmp 中，不把第三方全文重新发布到本站。人工核验范围以本文件和 research.json 为准。
