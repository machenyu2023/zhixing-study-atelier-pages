# 来源登记

来源及其支持范围的主记录保存在 `data/remote-sensing/catalog.json`；下列是阅读入口。用户给出的知识库要求保存为工作约定，不作为科学文献依据。

- SRC-0001：[NIST — Discussion of Rendering](https://math.nist.gov/~FHunt/appearance/render.html)，网页的方向辐射亮度、单位与 BRDF 积分关系；支持 RS-02-001。
- SRC-0002：[USGS — Landsat Collection 2 Surface Reflectance](https://www.usgs.gov/landsat-missions/landsat-collection-2-surface-reflectance)，产品定义及算法差异小节；支持 RS-04-001 的产品说明，不支持将教学近似称作其官方算法。
- SRC-0003：[CIMSS — Blackbody Radiation Lab](https://cimss.ssec.wisc.edu/wxwise/class/aos340/labs/lab2/lab2.html)，A–B 部分的光谱与谱峰实验说明；支持 RS-06-001 的实验设计。

核验日期：2026-09-12。尚未完成相应教材与 ATBD 全文核验。
