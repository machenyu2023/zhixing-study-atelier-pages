## 入库与交叉核验规则

- 先读 T1 教材和官方 ATBD，再用 T2 综述/经典论文解释模型差异，最后才引用 T3 教学资料作为实验入口。
- 每条公式登记“原文位置—本地变量名—单位—适用条件”；如果只看到摘要或网页简介，定位写“摘要/简介”，状态保持“待精读”。
- 同一问题的不同算法分开建记录：LaSRC 与 LEDAPS、6S 与其他大气传输模型、不同 BRDF/LST/介电模型、SMAP 被动与主动—被动土壤水分算法不得合成一个无条件结论。
- 资料入库时提取核心概念、公式、假设、参数范围、实验设计、典型图表、经典结论和可复现实验；避免复制长段原文。
- 每完成一篇来源精读，同步更新 `data/remote-sensing/catalog.json`、知识地图和变更记录，并把本页的“已定位待精读”改为带页码/章节的“已核验”。
